> **说明：** 本优化方案以**务实、低风险、易实施**为原则，优先解决当前问题，避免大规模重构。

## 四、架构设计优化

### 4.1 分层优化

**建议引入明确的分层架构:**

```

┌─────────────────────────────────────┐

│        Controller Layer             │  ← 接口层（仅处理 HTTP 请求/响应）

├─────────────────────────────────────┤

│         Service Layer               │  ← 业务逻辑层

│  ┌─────────────┬──────────────┐    │

│  │   Service   │  ServiceImpl │    │

│  └─────────────┴──────────────┘    │

├─────────────────────────────────────┤

│        Manager Layer (新增)         │  ← 通用业务处理层

│  - CacheManager                     │  （缓存、第三方服务调用）

│  - ThirdPartyManager                │

├─────────────────────────────────────┤

│         Mapper Layer                │  ← 数据访问层

└─────────────────────────────────────┘

```

**示例:**

```java

// Manager 层处理通用业务逻辑

@Component

@RequiredArgsConstructor

publicclassUserCacheManager {

    privatefinalRedisTemplate<String,Object> redisTemplate;

    privatefinalUserMapperuserMapper;

  

    publicUser getUserWithCache(LonguserId){

        StringcacheKey = "user:"+ userId;

        Useruser = (User) redisTemplate.opsForValue().get(cacheKey);

            if (user !=null) {

                redisTemplate.opsForValue().set(cacheKey, user,1,TimeUnit.HOURS);

            }

        }

        return user;

    }

}
```

```java
publicclassXssHttpServletRequestWrapperextendsHttpServletRequestWrapper {

        returncleanXSS(value);

    }

  

    privateString cleanXSS(Stringvalue){

        if (value ==null) returnnull;

        value = value.replaceAll("<","<").replaceAll(">",">");

        value = value.replaceAll("\\(","(").replaceAll("\\)",")");

        value = value.replaceAll("'","'");

        value = value.replaceAll("eval\\((.*)\\)","");

        value = value.replaceAll("[\"'][\\s]*javascript:(.*)[\"']","\"\"");

        value = value.replaceAll("script","");

        return value;
```
